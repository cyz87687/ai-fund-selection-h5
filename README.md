# AI自然语言To-C智能选基H5工具

> 劳动竞赛智慧服务赛道参赛项目

## 项目背景

本项目旨在开发一款面向C端用户的AI智能选基H5工具，用户通过自然语言描述投资需求（如风险偏好、投资期限、预期收益等），AI自动识别用户意图并推荐匹配的基金产品。工具结合了自然语言处理、基金数据分析和风险匹配算法，为用户提供个性化的基金推荐服务。

## 文件说明

| 文件 | 说明 |
|------|------|
| [AI自然语言选基H5工具PRD.md](AI自然语言选基H5工具PRD.md) | 产品需求文档（PRD），详细描述产品功能、设计思路和技术方案 |
| [AI智能选基H5.html](AI智能选基H5.html) | H5应用主页面，包含完整的交互功能和UI界面 |

## 使用方法

直接在浏览器中打开 `AI智能选基H5.html` 文件即可运行，无需安装任何依赖。

## 技术栈

- **Vue3** - 前端框架
- **Tailwind CSS** - 样式框架
- **ECharts** - 数据可视化图表
- **DeepSeek API** - 自然语言意图识别（deepseek-v4-flash）

## 功能概览

- 用户自然语言输入选基需求
- AI意图识别与数据转换
- 三要素客户画像（风险偏好、投资期限、预期收益）
- 基金推荐结果展示与详情链接
- 基金详情页跳转（模板：`https://financial.touker.com/publicfund/product?fundCode=XXX`）

## ⚠️ 风险提示

本工具使用**模拟脱敏数据**，仅供劳动竞赛演示使用，**不构成任何投资建议**。所有基金数据和推荐结果均为模拟生成，不代表真实市场表现。
